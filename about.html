About Me

Building backend systems, APIs, and data-driven web solutions

I am a Back-End Web Developer who focuses on the logic, structure, and systems behind modern web applications. I build backend solutions, API integrations, and database-driven applications that are practical, reliable, and easy to maintain.

I enjoy working on projects that include web application architecture, authentication systems, admin panels, REST APIs, and backend services built around real business needs. I like turning requirements into stable systems that support daily workflows and make complex processes easier to handle.

Alongside backend web development, I also work with data automation and system integration. I build solutions that connect databases, APIs, reporting tools, and office processes so data can move more clearly and reliably between different parts of a workflow.

My projects often involve ASP.NET, .NET Core, PHP, Laravel, Python, C#, JavaScript, WordPress, SQL and NoSQL databases, API development, and custom automation logic. I am especially interested in backend structures that can grow over time, stay easy to maintain, and remain useful in the long run.

I use this website to share my work, technical interests, and the kinds of systems I enjoy building.
